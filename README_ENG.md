# AO3 Skin — Golden Constellations

A dark site skin for Archive of Our Own (AO3), featuring gold accents, color-coded tags, and an additional version with a white reading page for better readability.

This skin is a **modification of an existing base skin** (dark navy background, gold accents, and a constellation-themed header image), on top of which most of the CSS has been rewritten and expanded: a new color palette per tag category, redesigned buttons, filter panel, pagination, blurb header, and more.

Part of the code that replaces the rating/warnings/category/status icons with readable text is adapted from the `removes-icons.css` snippet in [electricalice's Ao3-modular-skins repository](https://github.com/electricalice/Ao3-modular-skins), originally used in AO3's official "Plain Text" skin.

## Files

- **`skin_ao3_actualizado.css`** — the main skin, dark theme throughout the whole site.
- **`skin_ao3_lectura_blanca.css`** — the same skin, but with the chapter reading area on a white background with black text for easier reading. The rest of the page (header, tags, navigation) stays the same.

## Features

- Distinct color palette per tag category (fandom, relationships, characters, freeform, category, warnings), including a visual distinction between romantic and non-romantic relationships.
- Redesigned buttons, pagination, and filter panel (Sort and Filter) for visual consistency.
- Rating/warnings/category/status symbols shown as readable text instead of icons, grouped in a subtle box with separators.
- Reorganized blurb header: date, title, fandom, and classification each with their own spacing.
- Justified text for fic chapters.

## Installation

1. Copy the contents of whichever `.css` file you prefer.
2. On AO3, go to **My Preferences → Skins → My Skins → Create Skin**.
3. Paste the code into the CSS field.
4. Save it and select it as your active skin from Preferences.
